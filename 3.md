## 3. Cloudflare Dashboard Setup

### A. Worker Custom Domain

1. Vào [Cloudflare Dashboard](https://dash.cloudflare.com/) → `cuong.ngo`
2. Workers Routes → Add route:
   - Route: `ajinov5.cuong.ngo/*`
   - Service: `agent-gateway`
   - Environment: `production`
3. SSL/TLS → Overview → Set to Full (strict)

### B. DNS Records cho `api.ajinov5.cuong.ngo`

1. DNS → Add Record:
   - Type: `CNAME`
   - Name: `api.ajinov5`
   - Target: `<TUNNEL_ID>.cfargotunnel.com`
   - Proxy: ✅ (Orange cloud)
